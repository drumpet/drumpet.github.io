My First Article

May 1, 2024

Welcome to my blog. This is a sample article to demonstrate the simple blogging system.

Each article lives in its own directory under /blog/. This makes it easy to organize assets like images alongside the article content.

How This Works

The structure is simple:

blog/
  index.html          (blog listing)
  my-first-article/
    index.html        (this article)
    image.jpg         (any assets go here)
  another-article/
    index.html
    photo.png

To add a new article:

  1. Create a new directory under /blog/
  2. Add an index.html file with your content
  3. Place any images or assets in the same directory
  4. Add a link to the article in /blog/index.html

That's it. No build step, no CMS, just files and folders.
