# 블로그 + AI 협업 에디터 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Jekyll 기반 개인 홈페이지에 블로그를 붙이고, 브라우저에서 AI와 대화하며 글을 쓰고 GitHub에 저장·발행하는 에디터(`/write/`)를 만든 뒤 `anthonypaek.com`에 연결한다.

**Architecture:** 사이트는 GitHub Pages 기본 Jekyll(플러그인 없음)로 `_posts/*.md`를 렌더링한다. 에디터는 빌드 없는 바닐라 ES 모듈로, Claude/OpenAI/로컬 모델을 브라우저에서 직접 스트리밍 호출하고, GitHub Contents API로 private `drumpet/drafts`(초안)와 public `drumpet/drumpet.github.io`(발행)에 커밋한다. 서버·DB·Action 없음.

**Tech Stack:** Jekyll 3 (github-pages gem, Docker `ruby:3.3`로 로컬 빌드), 바닐라 JS ES modules, `marked`(jsDelivr), Node 25 내장 test runner, GitHub Contents API, Anthropic Messages API, OpenAI 호환 chat/completions, `gh` CLI.

스펙: `docs/superpowers/specs/2026-10-12-blog-cms-design.md`

## Global Constraints

- 저장소에 비밀값(API 키, 토큰)을 절대 커밋하지 않는다. 키는 브라우저 localStorage `write.settings`에만.
- 외부 JS 의존성은 에디터 미리보기용 `marked` 하나(`https://cdn.jsdelivr.net/npm/marked/lib/marked.esm.js`).
- 글 frontmatter 필드는 `title`, `date`(YYYY-MM-DD), `lang`(ko|en), `description` 네 개. 파일명 `_posts/YYYY-MM-DD-slug.md`, URL `/blog/<slug>/`.
- slug는 `^[a-z0-9-]+$`.
- Claude 기본 모델 `claude-opus-5-5`, `max_tokens: 16000`, `fallbacks: "default"` + 헤더 `anthropic-beta: server-side-fallback-2026-07-01`, 브라우저 헤더 `anthropic-dangerous-direct-browser-access: true`. `thinking` 파라미터는 보내지 않는다.
- 로컬 모델 기본 base URL `http://localhost:11434/v1`.
- `CNAME` 파일과 `_config.yml`의 `url: https://anthonypaek.com`은 **Task 9(도메인)에서만** 넣는다. 그 전에 넣으면 DNS가 준비되기 전에 사이트가 끊긴다.
- 커밋 메시지 끝에 `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>` 줄을 붙인다.
- 터미널의 `gh`는 `apaek` 계정(읽기 전용)이다. GitHub에 쓰는 `gh` 작업(Task 8, 9)은 `drumpet` 계정으로 로그인한 뒤 수행하고, 끝나면 `gh auth switch --user apaek`로 되돌린다.
- UI 문구는 사이트는 영어(기존 페이지와 일치), 에디터는 한국어.

### Task 2: 에디터 순수 로직 `write/post.js`

**Files:**
- Create: `write/post.js`, `write/test.mjs`

**Interfaces:**
- Produces:
  - `parseFrontmatter(text) → { fields: Record<string,string>, body: string }`
  - `serializePost(fields, body) → string` (키 순서 title, date, lang, description; 빈 값 생략)
  - `slugify(s) → string` (`[a-z0-9-]*`, 한글은 빈 문자열)
  - `defaultSlug(title, date) → string` (`slugify(title) || 'post-YYYYMMDD'`)
  - `slugFromPostPath(path) → string` (`_posts/2026-10-12-foo.md` → `foo`)
  - `postFilename(date, slug, existingPath) → string`
  - `extractDraft(text) → { draft: string|null, unclosed: boolean }`
  - `visibleText(text) → string` (`<draft>` 블록 제거)
  - `buildUserContent(draftText, userText) → string`
  - `buildSystemPrompt() → string`
  - `todayISO() → 'YYYY-MM-DD'` (로컬 시간)

- [ ] **Step 1: 실패하는 테스트 작성** — `write/test.mjs`

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import {
  parseFrontmatter, serializePost, slugify, defaultSlug, slugFromPostPath,
  postFilename, extractDraft, visibleText, buildUserContent, buildSystemPrompt, todayISO,
} from './post.js';

test('parseFrontmatter: basic fields and body', () => {
  const { fields, body } = parseFrontmatter('---\ntitle: Hello\ndate: 2026-10-12\nlang: ko\ndescription: 요약\n---\n\n본문\n');
  assert.deepEqual(fields, { title: 'Hello', date: '2026-10-12', lang: 'ko', description: '요약' });
  assert.equal(body, '\n본문\n');
});

test('parseFrontmatter: quoted values and colon in title', () => {
  const { fields } = parseFrontmatter('---\ntitle: "A: B \\"q\\""\ndescription: \'it\'\'s\'\n---\nx');
  assert.equal(fields.title, 'A: B "q"');
  assert.equal(fields.description, "it's");
});

test('parseFrontmatter: no frontmatter returns whole text as body', () => {
  const r = parseFrontmatter('just text\n---\nnot frontmatter');
  assert.deepEqual(r.fields, {});
  assert.equal(r.body, 'just text\n---\nnot frontmatter');
});

test('parseFrontmatter: hr line in body is not mistaken for the closer', () => {
  const r = parseFrontmatter('---\ntitle: T\n---\nabove\n\n---\n\nbelow');
  assert.equal(r.fields.title, 'T');
  assert.equal(r.body, 'above\n\n---\n\nbelow');
});

test('parseFrontmatter: empty frontmatter', () => {
  const r = parseFrontmatter('---\n---\nbody');
  assert.deepEqual(r.fields, {});
  assert.equal(r.body, 'body');
});

test('serializePost: order, quoting, trailing newline', () => {
  const out = serializePost({ description: 'd', lang: 'ko', title: 'A: B', date: '2026-10-12', slug: 'ignored' }, 'body\n\n');
  assert.equal(out, '---\ntitle: "A: B"\ndate: 2026-10-12\nlang: ko\ndescription: d\n---\n\nbody\n');
});

test('serializePost: omits empty fields', () => {
  assert.equal(serializePost({ title: 'T', date: '2026-01-01', lang: '', description: '' }, 'b'), '---\ntitle: T\ndate: 2026-01-01\n---\n\nb\n');
});

test('round trip', () => {
  const fields = { title: '두 번째: 글', date: '2026-10-12', lang: 'ko', description: 'x #1' };
  const r = parseFrontmatter(serializePost(fields, 'hello'));
  assert.deepEqual(r.fields, fields);
  assert.equal(r.body.trim(), 'hello');
});

test('slugify', () => {
  assert.equal(slugify('Hello, World!  Again'), 'hello-world-again');
  assert.equal(slugify('한글 제목'), '');
  assert.equal(slugify('  Café--Au Lait  '), 'cafe-au-lait');
  assert.equal(defaultSlug('한글', '2026-10-12'), 'post-20261012');
```

```js
export function parseFrontmatter(text) {
  const lines = String(text).split(/\r?\n/);
  if (lines[0].trim() !== '---') return { fields: {}, body: text };
  const end = lines.findIndex((l, i) => i > 0 && l.trim() === '---');
  if (end === -1) return { fields: {}, body: text };
  const fields = {};
  for (const line of lines.slice(1, end)) {
    const i = line.indexOf(':');
    if (i === -1) continue;
    const key = line.slice(0, i).trim();
    let value = line.slice(i + 1).trim();
    if (/^".*"$/.test(value)) {
      try { value = JSON.parse(value); } catch { value = value.slice(1, -1); }
    } else if (/^'.*'$/.test(value)) {
      value = value.slice(1, -1).replace(/''/g, "'");
    }
    if (key) fields[key] = value;
  }
  return { fields, body: lines.slice(end + 1).join('\n') };
}

function yamlScalar(v) {
  const s = String(v);
  const risky = /[:#\[\]{}&*!|>'"%@`]|^\s|\s$|^[-?]|^(true|false|yes|no|null|~)$/i;
  return risky.test(s) ? JSON.stringify(s) : s;
}

export function serializePost(fields, body) {
  const lines = ['---'];
  for (const key of FIELD_ORDER) {
    const v = fields[key];
    if (v === undefined || v === null || String(v).trim() === '') continue;
    lines.push(`${key}: ${yamlScalar(v)}`);
  }
  lines.push('---');
  return lines.join('\n') + '\n\n' + String(body).replace(/\s+$/, '') + '\n';
}
```

```js
// AI 제공자 호출. Anthropic Messages API와 OpenAI 호환 chat/completions 두 형식.

const ANTHROPIC_URL = 'https://api.anthropic.com/v1';

function trimSlash(u) { return String(u || '').replace(/\/+$/, ''); }

export function buildAnthropicRequest(p, system, messages) {
  return {
    url: `${ANTHROPIC_URL}/messages`,
    headers: {
      'content-type': 'application/json',
      'x-api-key': p.apiKey,
      'anthropic-version': '2023-06-01',
      'anthropic-dangerous-direct-browser-access': 'true',
      'anthropic-beta': 'server-side-fallback-2026-07-01',
    },
    body: { model: p.model, max_tokens: 16000, stream: true, system, messages, fallbacks: 'default' },
  };
}

export function buildOpenAIRequest(p, system, messages) {
  const headers = { 'content-type': 'application/json' };
  if (p.apiKey) headers.authorization = `Bearer ${p.apiKey}`;
  return {
    url: `${trimSlash(p.baseUrl)}/chat/completions`,
    headers,
    body: { model: p.model, stream: true, messages: [{ role: 'system', content: system }, ...messages] },
  };
}

export async function* sseData(stream) {
  const reader = stream.getReader();
  const dec = new TextDecoder();
  let buf = '';
  while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    buf += dec.decode(value, { stream: true });
    let i;
    while ((i = buf.indexOf('\n')) !== -1) {
      const line = buf.slice(0, i).replace(/\r$/, '');
      buf = buf.slice(i + 1);
      if (line.startsWith('data:')) yield line.slice(5).trim();
    }
  }
}

async function httpError(res) {
  const raw = await res.text().catch(() => '');
  let msg = raw.slice(0, 300);
  try { msg = JSON.parse(raw).error?.message || msg; } catch { /* keep raw */ }
  const e = new Error(`HTTP ${res.status}: ${msg}`);
  e.status = res.status;
  return e;
}

function normalizeStop(provider, raw) {
  if (!raw) return null;
  if (provider === 'anthropic') {
    if (raw === 'max_tokens') return 'length';
    if (raw === 'refusal') return 'refusal';
    return 'end';
  }
  if (raw === 'length') return 'length';
  if (raw === 'content_filter') return 'refusal';
  return 'end';
}

export async function streamChat({ provider, settings, system, messages, onText, signal, fetchImpl = fetch }) {
  const isAnthropic = provider === 'anthropic';
  const req = isAnthropic ? buildAnthropicRequest(settings, system, messages) : buildOpenAIRequest(settings, system, messages);
  const res = await fetchImpl(req.url, { method: 'POST', headers: req.headers, body: JSON.stringify(req.body), signal });
  if (!res.ok) throw await httpError(res);

  let text = '';
  let stop = null;
  for await (const data of sseData(res.body)) {
    if (data === '[DONE]') break;
    let ev;
    try { ev = JSON.parse(data); } catch { continue; }
    if (isAnthropic) {
      if (ev.type === 'content_block_delta' && ev.delta?.type === 'text_delta') { text += ev.delta.text; onText(text); }
      else if (ev.type === 'message_delta' && ev.delta?.stop_reason) stop = ev.delta.stop_reason;
      else if (ev.type === 'error') throw new Error(ev.error?.message || 'stream error');
    } else {
      if (ev.error) throw new Error(ev.error.message || 'stream error');
      const c = ev.choices?.[0];
      if (c?.delta?.content) { text += c.delta.content; onText(text); }
      if (c?.finish_reason) stop = c.finish_reason;
    }
  }
  return { text, stop: normalizeStop(provider, stop) };
}

export async function listModels(provider, p, fetchImpl = fetch) {
  let url, headers;
  if (provider === 'anthropic') {
    url = `${ANTHROPIC_URL}/models?limit=100`;
    headers = { 'x-api-key': p.apiKey, 'anthropic-version': '2023-06-01', 'anthropic-dangerous-direct-browser-access': 'true' };
  } else {
    url = `${trimSlash(p.baseUrl)}/models`;
    headers = p.apiKey ? { authorization: `Bearer ${p.apiKey}` } : {};
  }
  const res = await fetchImpl(url, { headers });
  if (!res.ok) throw await httpError(res);
  const json = await res.json();
  return (json.data || []).map((m) => m.id).filter(Boolean).sort();
}
```

```js
// GitHub Contents API 최소 래퍼. 토큰은 fine-grained PAT (Contents: read/write).

const API = 'https://api.github.com';

export function encodeContent(str) {
  const bytes = new TextEncoder().encode(str);
  let bin = '';
  for (let i = 0; i < bytes.length; i += 0x8000) bin += String.fromCharCode.apply(null, bytes.subarray(i, i + 0x8000));
  return btoa(bin);
}

export function decodeContent(b64) {
  const bin = atob(String(b64).replace(/\s/g, ''));
  const bytes = Uint8Array.from(bin, (c) => c.charCodeAt(0));
  return new TextDecoder().decode(bytes);
}

function encodePath(path) {
  return path.split('/').map(encodeURIComponent).join('/');
}

export function createGitHub(token, fetchImpl = fetch) {
  const base = {
    authorization: `Bearer ${token}`,
    accept: 'application/vnd.github+json',
    'x-github-api-version': '2022-11-28',
  };

  async function request(method, path, body) {
    const headers = body ? { ...base, 'content-type': 'application/json' } : base;
    const res = await fetchImpl(API + path, { method, headers, body: body ? JSON.stringify(body) : undefined });
    if (res.status === 404 && method === 'GET') return null;
    if (!res.ok) {
      let msg = '';
      try { msg = (await res.json()).message || ''; } catch { /* ignore */ }
      const e = new Error(`GitHub ${res.status}${msg ? ': ' + msg : ''}`);
      e.status = res.status;
      throw e;
    }
    if (res.status === 204) return null;
    return res.json();
  }

  const contents = (repo, path) => `/repos/${repo}/contents/${encodePath(path)}`;

  const api = {
    async getFile(repo, path) {
      const r = await request('GET', contents(repo, path));
      if (!r || Array.isArray(r)) return null;
      return { sha: r.sha, content: decodeContent(r.content) };
    },

    async listDir(repo, path) {
      const r = await request('GET', contents(repo, path));
      if (!Array.isArray(r)) return [];
      return r.filter((x) => x.type === 'file').map((x) => ({ name: x.name, path: x.path, sha: x.sha }));
    },

    async putFile(repo, path, content, message) {
      const attempt = async () => {
        const cur = await api.getFile(repo, path);
        const body = { message, content: encodeContent(content) };
        if (cur) body.sha = cur.sha;
        await request('PUT', contents(repo, path), body);
      };
      try {
        await attempt();
      } catch (e) {
        if (e.status === 409 || e.status === 422) await attempt();
        else throw e;
      }
    },

    async deleteFile(repo, path, message) {
      const cur = await api.getFile(repo, path);
      if (!cur) return;
      await request('DELETE', contents(repo, path), { message, sha: cur.sha });
    },
  };
  return api;
}
```

```js
export const DEFAULTS = Object.freeze({
  provider: 'anthropic',
  anthropic: { apiKey: '', model: 'claude-opus-5-5', baseUrl: '' },
  openai: { apiKey: '', model: '', baseUrl: 'https://api.openai.com/v1' },

  github: { token: '', siteRepo: 'drumpet/drumpet.github.io', draftsRepo: 'drumpet/drafts', siteUrl: 'https://anthonypaek.com' },
});

export function mergeSettings(base, patch) {
  const out = {};
  for (const [k, v] of Object.entries(base)) {
    const p = patch && patch[k];
    if (v && typeof v === 'object') out[k] = mergeSettings(v, p && typeof p === 'object' ? p : {});
    else out[k] = p === undefined || p === null ? v : p;
  }
  return out;
}

export function loadSettings() {
  try {
    const raw = localStorage.getItem(KEY);
    return mergeSettings(DEFAULTS, raw ? JSON.parse(raw) : {});
  } catch {
    return mergeSettings(DEFAULTS, {});
  }
}

export function saveSettings(s) {
  try { localStorage.setItem(KEY, JSON.stringify(s)); } catch { /* private mode etc. */ }
}

export function activeProvider(s) {
  const p = s[s.provider] || {};
  return { provider: s.provider, apiKey: p.apiKey || '', model: p.model || '', baseUrl: p.baseUrl || '' };
}

export function isConfigured(s) {
  const p = activeProvider(s);
  if (!s.github?.token || !p.model) return false;
  return s.provider === 'local' || !!p.apiKey;
}

function getPath(obj, path) { return path.split('.').reduce((o, k) => (o == null ? undefined : o[k]), obj); }
function setPath(obj, path, value) {
  const keys = path.split('.');
  let o = obj;
  for (const k of keys.slice(0, -1)) o = o[k] ?? (o[k] = {});
  o[keys[keys.length - 1]] = value;
}

export function toggleProviderFields(form) {
  const p = form.elements.provider.value;
  for (const fs of form.querySelectorAll('fieldset[data-provider]')) fs.hidden = fs.dataset.provider !== p;
}

export function fillForm(form, s) {
  for (const el of form.elements) {
    if (!el.name) continue;
    const v = getPath(s, el.name);
    el.value = v === undefined ? '' : v;
  }
  toggleProviderFields(form);
}

export function readForm(form) {
  const s = mergeSettings(DEFAULTS, {});
  for (const el of form.elements) {
    if (!el.name) continue;
    setPath(s, el.name, el.value.trim());
  }
  return s;
}
```

```js
function messageNode(m) {
  const div = document.createElement('div');
  div.className = `msg ${m.role}${m.error ? ' error' : ''}`;

    const chip = document.createElement('span');
    chip.className = 'note';
    chip.textContent = m.note;
    div.appendChild(document.createElement('br'));
    div.appendChild(chip);

// ---------- dirty / buffer ----------

function bufferKey(doc) { return `${BUFFER_PREFIX}${doc.kind}:${doc.slug || 'new'}`; }

let bufferTimer = null;
function markDirty() {
  state.dirty = true;
  setStatus('저장되지 않음');
  clearTimeout(bufferTimer);
  bufferTimer = setTimeout(() => {
    try { localStorage.setItem(bufferKey(state.doc), JSON.stringify({ savedAt: Date.now(), doc: state.doc })); } catch { /* ignore */ }
  }, 300);
}

function clearBuffers() {
  clearTimeout(bufferTimer);
  try {
    for (const k of Object.keys(localStorage)) if (k.startsWith(BUFFER_PREFIX)) localStorage.removeItem(k);
  } catch { /* ignore */ }
}

function latestBuffer() {
  let best = null;
  try {
    for (const k of Object.keys(localStorage)) {
      if (!k.startsWith(BUFFER_PREFIX)) continue;
      const v = JSON.parse(localStorage.getItem(k));
      if (!best || v.savedAt > best.savedAt) best = { key: k, ...v };
    }
  } catch { /* ignore */ }
  return best;
}

function guardDirty(next) {
  if (!state.dirty) return next();
  showBanner('저장되지 않은 변경이 있습니다. 버리고 계속할까요?', [['버리기', () => { state.dirty = false; next(); }], ['취소', () => {}]]);
}

function syncFromForm() {
  const d = state.doc;
  if (d.kind === 'post') {
    d.fields.title = els.title.value;
    d.slug = els.slug.value.trim();
    d.fields.description = els.description.value;
    d.fields.lang = els.lang.value;

function applyDraft(text) {
  state.undo.push(snapshot());
  if (state.undo.length > 10) state.undo.shift();
  const d = state.doc;
  if (d.kind === 'about') {
    d.body = text;
  } else {
    const { fields, body } = parseFrontmatter(text);
    for (const k of FIELD_KEYS) if (fields[k] !== undefined) d.fields[k] = fields[k];
    if (!d.slug && fields.slug) d.slug = slugify(fields.slug);
    d.body = body.replace(/^\n+/, '');
  }
  renderDoc();
  markDirty();
}

function undo() {
  const s = state.undo.pop();
  if (!s) return;
  Object.assign(state.doc, s);
  renderDoc();
  markDirty();
}

// ---------- chat ----------

function errorText(e) {
  let t = e.message || String(e);
  if (e.status === 401 || e.status === 403) t += ' — 설정에서 키를 확인하세요.';
  if (!e.status && /fetch/i.test(t) && settings.provider === 'local') t += ' — 로컬 서버가 켜져 있는지, CORS(OLLAMA_ORIGINS)와 mixed content를 확인하세요.';
  return t;
}

async function send() {
  const text = els.chatInput.value.trim();
  if (!text || state.busy) return;
  if (!isConfigured(settings)) { setStatus('설정이 필요합니다', { error: true }); openSettings(); return; }

  const p = activeProvider(settings);
  const history = state.doc.chat.filter((m) => m.role !== 'system').map((m) => ({ role: m.role, content: m.content }));
  const messages = [...history, { role: 'user', content: buildUserContent(docText(state.doc), text) }];

  state.doc.chat.push({ role: 'user', content: text });
  const assistant = { role: 'assistant', content: '' };
  state.doc.chat.push(assistant);
  els.chatInput.value = '';
  renderChat();

  state.busy = true;
  state.abort = new AbortController();
  setBusy(true);
  try {
    const { text: full, stop } = await streamChat({
      provider: p.provider, settings: p, system: buildSystemPrompt(), messages, signal: state.abort.signal,
      onText: (t) => { assistant.content = t; renderLastMessage(); },
    });
    assistant.content = full;
    const { draft, unclosed } = extractDraft(full);
    if (unclosed) assistant.note = '초안이 잘려 반영하지 않았습니다';
    else if (draft !== null) { applyDraft(draft); assistant.note = '초안 갱신됨'; }
    if (stop === 'length') addSystemLine('응답이 길이 제한으로 잘렸습니다.');
    if (stop === 'refusal') addSystemLine('모델이 요청을 거부했습니다.');
  } catch (e) {
    if (!assistant.content) state.doc.chat.pop();
    if (e.name === 'AbortError') addSystemLine('중지했습니다.');
    else addSystemLine(errorText(e), true);
  } finally {
    state.busy = false;
    state.abort = null;
    setBusy(false);
    renderChat();
    markDirty();
  }
}

function setBusy(busy) {

  els.btnSave.disabled = busy;
  els.btnPublish.disabled = busy;

function findPublishedPath(slug) {

async function loadChat(slug) {
  for (const p of [`drafts/${slug}.chat.json`, `archive/${slug}.chat.json`]) {
    const f = await gh.getFile(settings.github.draftsRepo, p);
    if (f) {
      try { return (JSON.parse(f.content).messages || []).map((m) => ({ role: m.role, content: m.content })); } catch { /* ignore */ }
    }
  }
  return [];
}

function fieldsFrom(parsed) {
  const out = { title: '', date: todayISO(), lang: 'ko', description: '' };
  for (const k of FIELD_KEYS) if (parsed[k] !== undefined) out[k] = parsed[k];
  return out;
}

async function loadSelection(value) {
  if (!value || !requireGitHub()) return;
  setStatus('불러오는 중…');
  try {
    let doc;
    if (value === 'about') {
      const draft = await gh.getFile(settings.github.draftsRepo, 'drafts/about.md');
      const src = draft || (await gh.getFile(settings.github.siteRepo, '_includes/about.md'));
      doc = { kind: 'about', slug: 'about', savedSlug: draft ? 'about' : null, publishedPath: '_includes/about.md', fields: {}, body: src ? src.content : '', chat: await loadChat('about') };
    } else if (value.startsWith('draft:')) {
      const slug = value.slice(6);
      const f = await gh.getFile(settings.github.draftsRepo, `drafts/${slug}.md`);
      const { fields, body } = parseFrontmatter(f ? f.content : '');
      doc = { kind: 'post', slug, savedSlug: slug, publishedPath: findPublishedPath(slug), fields: fieldsFrom(fields), body, chat: await loadChat(slug) };
    } else if (value.startsWith('post:')) {
      const path = value.slice(5);
      const slug = slugFromPostPath(path);
      const f = await gh.getFile(settings.github.siteRepo, path);
      const { fields, body } = parseFrontmatter(f ? f.content : '');
      doc = { kind: 'post', slug, savedSlug: null, publishedPath: path, fields: fieldsFrom(fields), body, chat: await loadChat(slug) };
    } else {
      return;
    }
    state.doc = doc;
    state.undo = [];
    state.dirty = false;
    renderDoc();
    setStatus('불러옴');
  } catch (e) {
    setStatus('불러오기 오류: ' + e.message, { error: true });
  }
}

function fail(msg) { setStatus(msg, { error: true }); return false; }

function validateForSave() {
  const d = state.doc;
  if (d.kind === 'post') {
    if (!d.slug) d.slug = defaultSlug(d.fields.title, d.fields.date || todayISO());
    els.slug.value = d.slug;
    if (!/^[a-z0-9-]+$/.test(d.slug)) return fail('slug는 영문 소문자·숫자·하이픈만 쓸 수 있습니다');
  }
  return true;
}

async function save() {
  if (state.busy || !requireGitHub() || !validateForSave()) return false;
  const d = state.doc;
  const repo = settings.github.draftsRepo;
  const title = docTitle(d);
  state.busy = true; setBusy(true);
  setStatus('저장 중…');
  try {
    await gh.putFile(repo, `drafts/${d.slug}.md`, docText(d), `Save draft: ${title}`);
    await gh.putFile(repo, `drafts/${d.slug}.chat.json`, chatJSON(d), `Save chat: ${title}`);
    if (d.savedSlug && d.savedSlug !== d.slug) {
      await gh.deleteFile(repo, `drafts/${d.savedSlug}.md`, `Rename draft: ${d.savedSlug} → ${d.slug}`);
      await gh.deleteFile(repo, `drafts/${d.savedSlug}.chat.json`, `Rename draft: ${d.savedSlug} → ${d.slug}`);
    }
    d.savedSlug = d.slug;
    state.dirty = false;
    clearBuffers();
    setStatus('저장됨');
    refreshPicker().catch(() => {});
    return true;
  } catch (e) {
    setStatus('저장 오류: ' + e.message, { error: true });
    return false;
  } finally {
    state.busy = false; setBusy(false);
  }
}

function siteUrl() {
  return LOCAL_HOSTS.has(location.hostname) ? settings.github.siteUrl.replace(/\/+$/, '') : location.origin;
}

async function publish() {
  const d = state.doc;
  if (d.kind === 'post') {
    if (!d.fields.title.trim()) return fail('제목이 비었습니다');
    if (!/^\d{4}-\d{2}-\d{2}$/.test(d.fields.date)) return fail('날짜는 YYYY-MM-DD 형식이어야 합니다');
  }
  if (!d.body.trim()) return fail('본문이 비었습니다');
  if (!(await save())) return;

  const site = settings.github.siteRepo;
  const drafts = settings.github.draftsRepo;
  const title = docTitle(d);
  const path = d.kind === 'about' ? '_includes/about.md' : postFilename(d.fields.date, d.slug, d.publishedPath);
  const verb = d.publishedPath && d.kind === 'post' ? 'Update' : 'Publish';
  state.busy = true; setBusy(true);
  setStatus('발행 중…');
  try {
    await gh.putFile(site, path, docText(d), `${verb}: ${title}`);
    await gh.putFile(drafts, `archive/${d.slug}.chat.json`, chatJSON(d), `Archive chat: ${title}`);
    await gh.deleteFile(drafts, `drafts/${d.slug}.md`, `Published: ${title}`);
    await gh.deleteFile(drafts, `drafts/${d.slug}.chat.json`, `Published: ${title}`);
    d.publishedPath = path;
    d.savedSlug = null;
    const url = d.kind === 'about' ? `${siteUrl()}/` : `${siteUrl()}/blog/${d.slug}/`;
    setStatus(`발행됨 → ${url} (약 1분 뒤 반영)`, { url });
    refreshPicker().catch(() => {});
  } catch (e) {
    setStatus('발행 오류: ' + e.message, { error: true });
  } finally {
    state.busy = false; setBusy(false);
  }
}
```

- [ ] **Step 1: GitHub 도메인 소유 검증** (사용자 작업, UI + GoDaddy)

github.com (drumpet) → Settings → Pages → "Add a domain" → `anthonypaek.com` 입력. 표시되는 TXT 레코드(이름 `_github-pages-challenge-drumpet`, 값은 화면의 코드)를 GoDaddy DNS에 추가하고, 반영 후 GitHub에서 Verify. 검증되면 다른 사용자가 이 도메인을 자기 Pages에 붙일 수 없다.

- [ ] **Step 2: GoDaddy DNS 변경** (사용자 작업; 외부 영향이 있으니 아래 표를 보고 직접 수행)

GoDaddy → My Products → anthonypaek.com → DNS.
- 삭제: 이름 `@`의 기존 A 레코드 전부(파킹 IP `76.223.105.230`, `13.248.243.5`), 이름 `www`의 기존 CNAME/A 레코드. "Forwarding"이나 "Website Builder"가 켜져 있으면 끈다.
- 추가:

| 타입 | 이름 | 값 | TTL |
|---|---|---|---|
| A | @ | 185.199.108.153 | 600 |
| A | @ | 185.199.109.153 | 600 |
| A | @ | 185.199.110.153 | 600 |
| A | @ | 185.199.111.153 | 600 |
| CNAME | www | drumpet.github.io | 600 |

확인(반영까지 수 분~1시간):
```bash
dig +short anthonypaek.com A          # 185.199.108.153 ~ 111.153 네 개
dig +short www.anthonypaek.com CNAME  # drumpet.github.io.
```
